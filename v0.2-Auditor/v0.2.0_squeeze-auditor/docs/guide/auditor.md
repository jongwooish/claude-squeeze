# squeeze-Auditor 창

← [가이드 목차](index.md)

시작 메뉴(macOS는 응용 프로그램, Linux는 앱 메뉴)의 **squeeze-Auditor**를 누르면 창이 열립니다. 터미널에서는 `squeeze auditor`.

창은 squeeze가 이 컴퓨터 안(`127.0.0.1`)에서만 띄우는 작은 페이지를 Edge나 Chrome 앱 창으로 보여 주는 것입니다. 실행할 때마다 바뀌는 열쇠가 있어야 열리고, 창을 닫으면 잠시 뒤 스스로 꺼집니다. 이미 열려 있으면 새로 띄우지 않고 그 창을 다시 엽니다. 언어는 왼쪽 아래에서 영어/한국어를 고릅니다.

## 대시보드

- **Claude Code 사용량**: 이 컴퓨터의 Claude Code 세션 기록(`~/.claude/projects/`)에 적힌 실제 토큰(입력, 캐시, 출력)의 합. 오늘 / 7일 / 30일.
- **squeeze가 막아낸 양**: squeeze 기록(`~/.squeeze/ledger.jsonl`)의 합. 바이트 ÷ 4로 계산한 추정치입니다.
- **날짜별 토큰**: 파란 막대는 사용, 위의 빨간 부분은 squeeze가 막은 양.
- **현재 5시간 사용 구간**: Claude Code가 사용량을 5시간 단위로 세는 방식을 흉내 낸 추정입니다. 공식 한도 수치는 아닙니다.
- **squeeze가 막은 것**: 종류별 횟수와 토큰.
- **최근 세션**: 세션별 현재 크기와 예산 대비 막대. 빨간색이면 예산을 넘었습니다.

## 절약 모드

| | 강하게 | 균형 (기본) | 가볍게 |
|---|---:|---:|---:|
| 출력 압축 시작 | 40줄 | 80줄 | 150줄 |
| 큰 파일 기준 | 250줄 | 400줄 | 800줄 |
| 예산 일시 정지 | 100K | 150K | 200K |
| 이어가기 시작 | 80K | 120K | 160K |

모드를 고르면 숫자가 한 번에 바뀝니다. 사용자 설정에서 하나라도 바꾸면 "직접 설정"이 됩니다.

## 사용자 설정

모든 값을 바꿀 수 있습니다. 저장하면 `~/.squeeze/config.json`에 쓰고, 다음 Claude Code 메시지부터 바로 적용됩니다. 특정 프로젝트만 다르게 하려면 그 프로젝트의 `.squeeze/config.json`에 바꿀 키만 적으세요.

## 고정비 진단

위 [4가지 차단 기능 → 고정비](blockers.md#4-고정비-차단) 참고. 대상에서 프로젝트 또는 Claude 데스크톱 앱을 고릅니다.

## 이어가기

프로젝트별 `.squeeze/handoff/`와 데스크톱 앱용 `~/.squeeze/handoff/desktop/`의 메모를 최신순으로 보여 줍니다.

## 연결된 환경

Claude Code와 데스크톱 앱을 연결·해제하고, 데스크톱 앱이 읽을 수 있는 폴더를 정합니다. "이전 버전 훅"이라고 나오면 **다시 연결**을 눌러 v0.2 차단 기능을 추가하세요.

### 데스크톱 앱에서 쓰는 법

연결하고 앱을 다시 켜면, 채팅에서 이렇게 부탁하면 됩니다.

- "내 앱 로그에서 마지막 에러 읽어 줘" → Claude가 `tail_log`/`read_log`로 줄인 로그만 읽습니다. 긴 로그를 붙여 넣을 필요가 없습니다.
- 대화가 길어지면 "이어가기 저장해 줘" → 새 채팅에서 "이어가기 불러와 줘".

허용한 폴더 밖은 읽을 수 없습니다.

## 데이터가 저장되는 곳

| 위치 | 내용 |
|---|---|
| `~/.squeeze/config.json` | 전체 설정 |
| `~/.squeeze/ledger.jsonl` | squeeze가 막은 기록 (대시보드) |
| `~/.squeeze/sessions/` | 세션별 읽은 파일 목록, 예산·이어가기 상태 (7일 뒤 정리) |
| `~/.squeeze/backups/` | 바꾸기 전 Claude 설정 파일 원본 |
| `~/.squeeze/mcp-measure.json` | MCP 서버 측정 결과 |
| `<프로젝트>/.squeeze/handoff/` | 이어가기 메모 |
| `<프로젝트>/.squeeze/raw/` | 압축 전 전체 출력 (v0.1과 같음) |
