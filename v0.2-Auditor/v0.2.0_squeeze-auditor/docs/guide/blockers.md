# 4가지 차단 기능

← [가이드 목차](index.md)

## 왜 v0.1과 다르게 막나

v0.1은 "이 출력 하나가 긴가?"만 봤습니다. 하지만 토큰이 새는 큰 이유는 따로 있습니다. Claude Code는 메시지마다 **지금까지의 대화 전체와 고정으로 붙는 것들**을 다시 보냅니다. 그래서 같은 내용이 여러 번 들어오거나, 대화가 커지거나, 매번 따라붙는 게 많으면 메시지 하나하나가 비싸집니다.

v0.2는 그래서 **세션 전체**를 봅니다: 전에 무엇을 읽었는지(기억), 지금 얼마나 커졌는지(누적 크기), 무엇이 실제로 쓰였는지(사용 기록).

## 1. 중복 읽기 차단

- **언제**: Claude가 이번 세션에서 이미 통째로 읽은 파일을, 바뀌지 않았는데 또 통째로 읽으려 할 때.
- **판단**: 수정 시각·크기가 같으면 내용 해시까지 비교합니다. 하나라도 다르면 통과.
- **막는 방식**: Read를 거부하고 "이미 읽은 내용을 쓰라, 일부만 필요하면 offset/limit으로 읽으라"고 알려 줍니다.
- **다시 허용**: 파일이 바뀌면 바로, 대화가 압축(`/compact` 또는 자동 압축)되면 기록을 지웁니다. Claude가 정말 다시 필요하면 `limit`을 붙여 읽으면 통과합니다.
- **끄기**: 사용자 설정 → 파일 읽기 → "안 바뀐 파일 다시 읽기 차단".

## 2. 예산 일시 정지

- **언제**: 메시지를 보내는 순간, 세션 크기(컨텍스트 토큰)가 예산(기본 150K)을 넘었을 때.
- **크기 측정**: Claude Code 세션 기록의 마지막 응답에 적힌 실제 입력 토큰(입력 + 캐시 생성 + 캐시 읽기)을 씁니다.
- **막는 방식**: 메시지를 한 번 멈추고 `/compact`나 `/clear`를 권합니다. 그래도 보내려면 **↑ 키로 메시지를 불러와 다시 보내면** 통과합니다. 그 뒤로는 세션이 예산의 50%만큼 더 커질 때까지 다시 묻지 않습니다.
- **예외**: `/`로 시작하는 명령은 막지 않습니다. 메시지에 `SQUEEZE_SKIP`을 넣어도 통과합니다.

## 3. 긴 세션 이어가기 (핸드오프)

- **언제**: Claude가 답을 끝내려는 순간(Stop), 세션이 이어가기 크기(기본 120K)를 넘었을 때. 세션당 한 번.
- **막는 방식 (메모 모드, 기본)**: 바로 끝내지 않고, Claude에게 `.squeeze/handoff/<시각>-<세션>.md`에 이어가기 메모(목표, 한 일, 결정과 제약, 건드린 파일, 다음 할 일, 남은 질문; 600단어 이내)를 쓰게 합니다. 그리고 "/clear 하세요"라고 한 줄 알려 줍니다.
- **새 세션**: `/clear`(또는 새로 시작)하면 squeeze가 가장 최근의, 아직 안 쓴 48시간 이내 메모를 새 세션에 넣어 줍니다. 대화 전체(예: 150K) 대신 메모(약 1K)로 시작합니다.
- **알림 모드**: 메모 없이 "/compact 하세요"라고 알리기만 합니다.
- 메모는 평범한 Markdown 파일이라 `/clear` 전에 열어서 고쳐도 됩니다. 이어가기 탭에서도 볼 수 있습니다.

## 4. 고정비 차단

메시지마다 **내가 글자를 치기 전부터** 함께 보내지는 것들입니다.

| 종류 | 예 |
|---|---|
| 메모리 파일 | `~/.claude/CLAUDE.md`, 프로젝트와 상위 폴더의 `CLAUDE.md`, `CLAUDE.local.md` |
| 불러온 파일 | `CLAUDE.md` 안의 `@파일` |
| 스킬·에이전트 | 각 설명 부분 |
| MCP 서버 | 서버가 알려 주는 도구 목록 전체 |

- **고정비 진단 탭**에서 항목별 토큰을 보여 줍니다. MCP 서버는 **측정**을 누르면 그 서버를 잠깐 실행해 도구 목록 크기를 잽니다.
- **끄기**를 누르면 Claude Code 자체 스위치(`/mcp`에서 끄는 것과 같은 `disabledMcpServers`)로 그 프로젝트에서만 끕니다. 다음 세션부터 적용되고, **켜기**로 되돌립니다. 데스크톱 앱 서버는 설정에서 잠시 빼 두었다가 켜면 되돌려 놓습니다.
- **자동 끄기**(기본 꺼짐): 사용자 설정 → 고정비에서 켜면, 프로젝트에서 14일 동안 한 번도 안 쓴 MCP 서버를 세션 시작 때 끕니다.
- 팁: 큰 `CLAUDE.md`는 자주 안 쓰는 부분을 다른 파일로 빼고 경로만 적어 두면, 필요할 때만 읽힙니다. 같은 줄이 반복되면 지우는 것만으로 공짜 절약입니다.

## 안전 원칙 (v0.1과 같음)

- 훅은 어떤 오류가 나도 **아무 출력 없이** 끝나고 Claude Code는 평소처럼 진행합니다.
- squeeze는 도구 실행을 대신 **승인하지 않습니다**. 막거나 조용히 있을 뿐입니다.
- 네트워크로 아무것도 보내지 않습니다.
