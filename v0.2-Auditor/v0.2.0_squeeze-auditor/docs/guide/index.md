## 3줄 요약

1. 설치 파일을 실행하고 시작 메뉴의 **squeeze-Auditor**를 열어 **Claude Code 연결**을 누르면 모든 프로젝트에 적용됩니다.
2. squeeze가 같은 파일 다시 읽기, 너무 커진 세션, 긴 세션, 매번 따라붙는 고정비를 막아 줍니다. v0.1의 긴 출력 압축도 그대로 동작합니다.
3. 대시보드에서 실제 사용량과 squeeze가 막아낸 양을 확인하고, 절약 모드·사용자 설정에서 세기를 바꿉니다.
