# 동작 원리

← [가이드 목차](index.md)

## 왜 토큰이 새는가

Claude Code는 요청할 때마다 **지금까지의 대화 전체**를 다시 보냅니다. 명령 출력도 대화의 일부라서, `npm install` 로그 500줄이 한 번 들어오면 그 뒤 모든 턴에 따라붙습니다. 정작 필요한 건 "성공" 한 줄이나 에러 몇 줄인데도요.

squeeze는 이 출력이 **처음부터 컨텍스트에 들어오지 않게** 막습니다.

## 두 개의 훅

`squeeze init`은 `.claude/settings.json`에 Claude Code의 `PreToolUse` 훅 두 개를 등록합니다. 도구가 실행되기 **직전에** 호출됩니다.

### Bash 가드 (`squeeze hook pre-bash`)

1. Claude가 실행하려는 명령을 단순 명령 단위(`;`, `&&`, `|` 기준)로 나눕니다.
2. `sudo`, `npx`, `FOO=bar` 같은 앞부분을 건너뛰고 실제 프로그램과 서브커맨드를 봅니다.
3. 출력이 많은 조합이면(`npm install`, `go test`, `cargo build`, `pytest`, `make`, `apt-get install`, `journalctl`, `docker build`, `kubectl logs`, `git log` 등) **거부하면서 힌트**를 돌려줍니다: `squeeze run -- '<원래 명령>'`으로 다시 실행하라고.
4. 이미 출력이 제한된 명령은 건드리지 않습니다: `| tail -20`, `| grep`, `-n 50`, `> out.txt`, `--quiet`, `--version` 등.

### Read 가드 (`squeeze hook pre-read`)

`offset`/`limit` 없이 400줄이 넘는 텍스트 파일을 통째로 읽으려 하면 거부하고, **줄 번호가 붙은 목차**를 돌려줍니다. Claude는 필요한 구간만 다시 읽습니다. 그래도 전체가 필요하면 `limit=<전체 줄 수>`로 읽으면 통과합니다.

목차는 확장자별로 만듭니다: Markdown 제목, Rust/Go/Python/JS/TS 함수·타입, YAML 최상위 키, nginx 같은 `.conf`의 블록, Terraform 리소스 등. 모르는 형식은 일정 간격의 줄을 보여줍니다.

## 왜 "명령을 몰래 바꾸기"가 아니라 "거부 + 힌트"인가

Claude Code 훅은 명령을 바꿔치기할 수도 있지만, 그러려면 그 명령을 **승인**해야 합니다. 그러면 사용자의 권한 확인 단계를 건너뛰게 됩니다. squeeze는 절대 대신 승인하지 않습니다. 훅이 할 수 있는 건 "조용히 있기" 또는 "거부 + 힌트" 둘뿐이고, 다시 실행하는 `squeeze run`도 평소 권한 규칙을 그대로 따릅니다.

대가는 짧은 왕복 한 번입니다. `CLAUDE.md`에 들어간 4줄 안내 덕분에 Claude가 처음부터 `squeeze run`을 쓰는 경우가 많아 이 왕복도 줄어듭니다.

## 압축 규칙

출력이 **80줄 이하이고 8KB 이하면 원본 그대로** 둡니다. 그보다 길면:

1. ANSI 색상 코드를 지우고, `\r`로 덮어쓰는 진행률 표시는 마지막 상태만 남깁니다.
2. **처음 8줄, 마지막 20줄**은 항상 남깁니다.
3. 에러·경고 줄을 찾아 **앞뒤 2줄 문맥**과 함께 남깁니다. 들여쓰기된 다음 줄(스택 트레이스, 컴파일러 소스 표시)은 최대 12줄 더 남깁니다.
4. 같은 모양의 메시지(숫자만 다른 경우)는 **한 번만 보여주고 개수**를 붙입니다: `… [same message 29 more times] …`
5. 남길 줄이 너무 많으면 **에러를 경고보다 먼저** 고릅니다.
6. 생략한 부분은 `… [N lines omitted] …`로 표시하고, 마지막 줄에 원본 크기·압축 크기·전체 로그 경로·종료 코드를 적습니다.

`0 errors`, `failed: 0`, `no warnings` 같은 줄은 에러로 치지 않습니다.

## 데이터는 어디에 남나

- `.squeeze/raw/<시각>-<id>.log`: 전체 출력. 최근 50개만 유지, 권한 0600.
- `.squeeze/ledger.jsonl`: 이벤트마다 한 줄(종류, 명령, 압축 전/후 바이트). `squeeze report`가 읽습니다.
- `squeeze clip`은 프로젝트 밖에서 쓰므로 `~/.squeeze/`에 남깁니다. `squeeze report --global`로 봅니다.

squeeze에는 네트워크 코드가 없습니다. 아무것도 외부로 보내지 않습니다.

## 실패해도 안전하게

훅은 입력이 이상하거나, 파일이 없거나, 내부에서 패닉이 나도 **아무 출력 없이 종료 코드 0**으로 끝납니다. Claude Code는 squeeze가 없는 것처럼 계속 동작합니다.
